# Lieux, univers et chronologie

**Monde** garde le reste du monde de votre histoire, à côté de ses
[personnages](./characters-and-authors.md). Il comporte trois onglets :

| Onglet | Ce qu’il contient |
| --- | --- |
| **Lieux** | Les villes, les pièces et les routes que traverse votre histoire. Un lieu peut se trouver dans un autre : une pièce dans une maison, dans une ville. |
| **Univers** | Les coutumes, les histoires, les règles de votre monde. |
| **Chronologie** | Ce qui arrive, dans le temps propre de l’histoire (« An 3, printemps »), avec l’endroit où cela se passe et qui est là. |

Tout s’enregistre pendant que vous tapez et se synchronise comme le reste du
coffre.

## Ouvrir le monde {#open-the-world}

- Dans **Écrire**, cliquez sur **Monde** sous **Monde** dans la barre
  latérale. Vous voyez alors le monde de tous les projets.
- Dans un projet, cliquez sur l’onglet **Monde** sous le nom du projet, dans
  la liste (`⌃3` ; **Alt+3** sous Windows et Linux). Ou faites un clic droit
  sur le projet dans la barre latérale et choisissez **Monde**. Vous voyez
  alors le monde de ce projet.
- Appuyez sur `⌘G` puis `L`. Dans un projet, cela ouvre l’onglet Monde du
  projet ; partout ailleurs, celui du coffre.
- Appuyez sur `⌘P` et choisissez **Monde : lieux**, **Monde : univers** ou
  **Monde : chronologie**.

Le menu en haut de la page, **Tous les projets** ou le nom d’un projet,
choisit de qui il montre le monde.

## Ajouter une entrée {#add-an-entry}

1. Choisissez **Lieux**, **Univers** ou **Chronologie** en haut de la page.
2. Appuyez sur **Nouveau lieu**, **Nouvelle entrée** ou **Nouvel événement**,
   et tapez son nom.
3. Remplissez l’entrée à droite.

Chaque entrée a un **Nom**, **En une ligne** (un court résumé qui s’affiche
dans la liste), des **Notes**, et **Appartient à** : **Tous les projets**, ou
un projet, comme pour les personnages. Une nouvelle entrée créée dans le
monde d’un projet appartient à ce projet.

| Type | Il a aussi |
| --- | --- |
| Lieu | **Dans** : le lieu où il se trouve, ou **Nulle part ailleurs (premier niveau)**. **Ce qui se passe ici** liste les événements de la chronologie qui s’y déroulent. |
| Événement | **Quand, dans l’histoire**, par exemple *An 3, printemps* ou *la nuit de l’incendie*. **Où** : l’un de vos lieux. **Qui est là** : les personnages du projet. |

La chronologie liste les événements dans l’ordre que vous fixez, et non par
date, puisque l’histoire a son propre temps. Pour déplacer un événement,
ouvrez-le et utilisez les flèches **Plus tôt** et **Plus tard** à côté de
**Ordre dans la chronologie**.

## Voir ce qu’amène un document {#see-what-a-document-brings-in}

Dans un document d’Écrire, ouvrez le panneau **Infos** (`⇧⌘I`) et choisissez
son onglet **Monde**. Il liste :

- Les **personnages** qu’amène le document : mentionnés avec @, ou nommés
  dans le texte.
- Les **lieux** et l’**univers** qu’il nomme.
- Les pages de **recherche** qui lui sont liées.

Cliquez sur un personnage, un lieu ou une entrée d’univers pour voir une ligne
à son sujet, puis sur **Ouvrir** pour aller à sa fiche. Cliquez sur une page
de recherche pour l’ouvrir à côté de la page.

Les lieux et l’univers ne peuvent pas encore être liés depuis le texte : φ Poiesis
les retrouve donc d’après leur nom dans le texte.

## Supprimer une entrée {#delete-an-entry}

Appuyez sur **Supprimer**, au pied de l’entrée. φ vous demande d’abord
confirmation. L’entrée va dans la [corbeille](./organizing.md#trash), d’où
vous pouvez la restaurer. Les lieux qui se trouvaient dans un lieu supprimé
remontent d’un niveau.

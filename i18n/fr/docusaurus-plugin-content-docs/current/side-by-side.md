# Documents côte à côte

Parfois, la page que vous écrivez a besoin d’une autre ouverte à côté : la
recherche de ce chapitre, une note d’il y a des mois, le chapitre précédent, ou
ce que vous avez écrit ce même jour l’an dernier. φ ouvre jusqu’à **trois
documents côte à côte**, tous modifiables.

## Ouvrir un document à côté

Le plus simple : la **vue partagée.** Cliquez sur le bouton en colonnes de la
barre au-dessus de la page (ou appuyez sur `⌘\`). Un volet vide s’ouvre à
côté de votre document et la barre latérale glisse. Parcourez ce qu’il faut —
n’importe quelle liste, n’importe quel mode — et rien ne change sur la page
tant que vous ne choisissez pas un document : il remplit le volet vide. Plutôt
chercher par nom ? **Chercher par nom** dans le volet vide ouvre un sélecteur.
Changé d’avis ? Son **×** (ou `⌘W`) le ferme.

Ou sans volet vide : chacune de ces actions ouvre un document à côté du vôtre
aussitôt :

- **⌥-clic** sur un document de la liste, un chapitre du plan d’un projet, un
  lien de recherche sous le titre d’une page de recherche, ou un document lié
  dans **Infos → Liens**.
- **⌘⌥-clic** sur un `[[lien]]` du texte (en mode lecture, ⌥-clic suffit).
- **Ouvrir à côté** dans le menu ⋮ d’un document ou son menu contextuel.
- **Ouvrir à côté…** — dans le ⋮ du document ou la palette `⌘P`. Un sélecteur
  s’ouvre, qui commence par ce qui est utile ici :
  - pour un chapitre : la recherche de son projet et les documents liés ;
  - pour une entrée du journal : le même jour les années précédentes et les
    entrées juste avant ;
  - puis les documents ouverts récemment. Taper cherche partout.
- Dans la palette `⌘K`, **⌥↵** ouvre le document en surbrillance à côté plutôt
  qu’à la place de celui où vous êtes.

Un document déjà ouvert à côté n’est pas ouvert deux fois : il devient celui où
vous êtes. Avec trois ouverts, un nouveau prend la place du volet le plus à
droite où vous n’écrivez pas.

## N’importe quel mode, à côté de n’importe quel autre

Un volet peut contenir un document de n’importe quel mode, et en ouvrir un à
côté **ne change jamais le mode où vous êtes**. Une note ou une page de
recherche à côté d’un chapitre, c’est toujours Écrire : la barre latérale et la
liste sont celles d’Écrire, et fermer la note vous laisse dans Écrire. Chaque
volet garde l’allure de son document : une entrée du journal sa date, un
chapitre son objectif.

## Le volet où vous écrivez

Cliquez dans un volet pour y écrire. Ce volet — l’actif, avec un fin trait de la
couleur du mode en haut — est celui sur lequel agit tout le reste : le panneau
**Infos**, **Rechercher** (`⌘F`), les **Détails** (ⓘ), le menu ⋮ du document et
`⌘W`. Chaque volet affiche son propre nombre de mots dans son coin.

Chaque volet a une petite en-tête avec son titre et :

- **+** (sur le dernier) — un autre volet vide, pour un troisième document
- **⋮** — **Ouvrir seul** (ferme les autres), **Déplacer à gauche**,
  **Déplacer à droite**, **Fermer le volet**.
- **×** — ferme ce volet.

Un simple clic dans la liste ouvre ce document **à la place du** volet actif,
comme sur une page seule.

## La barre latérale en vue partagée

Dès que plus d’un document est ouvert, la barre latérale et la liste s’écartent
pour laisser la place aux pages. Cliquez sur **☰** à gauche de la barre
au-dessus des pages (ou appuyez sur `⌘0`) et elles glissent par-dessus les
volets ; choisissez un document, appuyez sur `Échap` ou cliquez à côté pour les
renvoyer.

Aller vers autre chose qu’un document — un tableau, le calendrier, le graphe,
l’Accueil d’un mode — l’affiche dans la disposition habituelle. **Retour**
(`⌘[`) ramène vos volets, et sur l’Accueil, **Continuer** rouvre la vue
partagée où vous écriviez en dernier.

## La largeur des volets

Faites glisser le trait entre deux volets pour en élargir un, ou cliquez sur le
trait et utilisez `←` `→`. φ retient les largeurs de chaque coffre sur cet
ordinateur. Dans une fenêtre trop étroite pour tous les volets, ceux qui ne
tiennent pas se replient en fins onglets sur le bord droit : cliquez sur l’un
d’eux pour le faire revenir.

## Le Sanctuaire avec des volets

Le [Sanctuaire](focus-and-writing-modes.md) (`⌘.`) garde vos volets et retire
tout ce qui les entoure ; les boutons de chaque volet n’apparaissent qu’en
pointant son en-tête. L’atténuation par phrase et le défilement machine à écrire
ne s’appliquent qu’au volet où vous écrivez : les autres restent entiers, pour
être lus.

## Revenir à une seule page

Fermez des volets (**×**, `⌘W` sur celui où vous êtes, ou `⌥⌘W` pour fermer tous
les autres) jusqu’à ce qu’il n’en reste qu’un : la disposition habituelle
revient, avec ce document ouvert.

## Raccourcis

| Action | Raccourci |
| --- | --- |
| Vue partagée (un volet vide à côté) | `⌘\` |
| Afficher la barre latérale par-dessus les volets | `⌘0` |
| Volet précédent · volet suivant | `⌃⌘←` · `⌃⌘→` |
| Fermer le volet où vous êtes | `⌘W` |
| Fermer les autres volets | `⌥⌘W` |

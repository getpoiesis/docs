# Notes et capture rapide

**Notes** est le mode de tout ce qui gravite autour de votre écriture : une
idée, une source, une phrase entendue au passage, une réflexion sur le
chapitre quatre. Une note n’a ni statut ni objectif de mots. Vous tapez votre
idée, vous appuyez sur Entrée et vous reprenez votre travail.

## Noter une idée {#capture-a-thought}

1. Choisissez **Notes** dans le sélecteur de mode, en haut de la barre
   latérale (`⌘2`). Notes s’ouvre sur sa page d’**Accueil**.
2. Cliquez sur **Notez une idée…** et tapez.
3. Pour étiqueter la note, ajoutez un mot précédé de `#`, par exemple
   `#idée`. Pour la lier à un document, tapez `[[` puis le titre du document.
4. Appuyez sur Entrée. La note est enregistrée et la zone se vide, prête
   pour l’idée suivante.

La note ne s’ouvre pas : vous restez là où vous étiez. Elle apparaît en tête
de **Modifié récemment** et dans **Toutes les notes**.

- Une idée courte devient le titre de la note.
- Une idée longue est raccourcie pour former le titre. Le texte de la note la
  conserve en entier.
- Seul le premier `#mot` devient une étiquette. Le mot reste aussi dans le
  texte, tel que vous l’avez écrit.

## Noter depuis une liste {#capture-from-a-list}

La même zone se trouve en haut de la liste quand vous affichez **Toutes les
notes**, un dossier ou une étiquette. La note est rangée en fonction de la
liste affichée :

| Vous affichez | La note est rangée |
| --- | --- |
| **Toutes les notes** | Hors de tout dossier, avec son premier `#mot` pour étiquette. |
| Un dossier | Dans ce dossier, avec son premier `#mot` pour étiquette. |
| Une étiquette | Sous cette étiquette, quoi que vous ayez tapé. |

Pour écrire une note plus longue, cliquez sur **+** en haut de la liste
(**Nouvelle note**) ou, depuis Notes, appuyez sur `⌘N`. Si vous cliquez sur
**+** alors que vous êtes dans un dossier, la nouvelle note est rangée dans
ce dossier.

## L’Accueil de Notes {#notes-home}

Notes s’ouvre sur l’Accueil. À gauche, vous trouvez :

- **Notez une idée…** : le moyen le plus rapide de créer une note.
- **Modifié récemment** : les dernières notes que vous avez modifiées. Pour
  chacune, vous voyez depuis combien de temps et sa première ligne. **Toutes
  les notes** ouvre la liste complète.
- **Actions en cours** : les éléments des listes de tâches de vos notes qui
  figurent sur un tableau et ne sont pas encore terminés. Cette section
  n’apparaît que s’il y en a. Voir [Tableaux](./boards).

À droite, vous trouvez :

- Le mois. Plus un jour est foncé, plus vous avez modifié de notes ce
  jour-là. **Calendrier** ouvre le calendrier.
- Vos notes **Favoris**.
- Les **Étiquettes** que vous utilisez le plus. Cliquez sur une étiquette
  pour afficher ses notes.

## Retrouver une note {#find-a-note-again}

Dans Notes, la barre latérale donne accès à ces lieux :

| Lieu | Ce qu’il contient |
| --- | --- |
| **Toutes les notes** | Toutes les notes qui n’appartiennent à aucun projet. |
| **Favoris** | Les notes que vous avez mises en favori. |
| **Non liées** | Les notes qu’aucun lien ne relie au reste : rien ne pointe vers elles et elles ne pointent vers rien. Pratique pour repérer celles que vous n’avez pas encore rattachées à quoi que ce soit. |
| **Dossiers** | Vos dossiers, chacun avec le nombre de notes qu’il contient. Le **+** à côté du titre crée un dossier. |
| **Étiquettes** | Toutes les étiquettes de vos notes, chacune avec son nombre de notes. |

Chaque liste commence par un champ de recherche, qui la filtre d’après le
titre, les premières lignes et les étiquettes. Chaque liste peut aussi être
triée : **Modifié**, **Créé** ou **Titre**.

`⌘K` retrouve n’importe quel document par son nom, où que vous soyez dans φ.
Voir [Rechercher et remplacer](./search-and-replace).

## Mettre une note en favori {#star-a-note}

Mettez en favori les notes que vous ouvrez le plus souvent. Il y a trois
façons de le faire :

- Cliquez sur le **⋮** en haut de la note ouverte, puis sur **Mettre en
  favori**.
- Faites un clic droit sur la note dans une liste (ou cliquez sur son **⋮**),
  puis choisissez **Mettre en favori**.
- Cliquez sur l’étoile dans la page **Détails…** de la note.

Refaites la même chose pour retirer la note des favoris.

Les notes favorites sont réunies sous **Favoris**, dans la barre latérale et
sur l’Accueil. Une petite étoile les signale aussi dans toutes les listes.

Quand une note est rangée dans un dossier, sa ligne affiche le nom de ce
dossier. C’est le cas dans **Toutes les notes** et dans toutes les autres
listes, sauf celle du dossier lui-même.

## Étiqueter une note {#tag-a-note}

Une étiquette réunit des notes, quel que soit leur dossier. Une note peut
porter autant d’étiquettes que vous voulez.

- **Ajouter une étiquette** : ouvrez les **Détails…** de la note, tapez dans
  **+ Étiquette** et appuyez sur Entrée. Un `#mot` dans une idée notée au vol
  ajoute aussi une étiquette.
- **Retirer une étiquette** : dans les Détails, cliquez sur le **×** de
  l’étiquette.
- **Voir les notes d’une étiquette** : cliquez sur l’étiquette sous
  **Étiquettes** dans la barre latérale, sur l’Accueil ou dans les Détails.

Dans une liste, chaque note affiche sa première étiquette sous sa première
ligne.

:::tip Notes et pièces sont un même type de document

Une pièce est un texte du mode Écrire qui n’appartient à aucun projet. Une
note peut devenir une pièce, et une pièce peut devenir une note.

- Pour transformer une note en pièce, faites un clic droit dessus (ou passez
  par son **⋮**) et choisissez **Déplacer vers les pièces d’Écrire**.
- Pour transformer une pièce en note, choisissez **Déplacer vers Notes**.

Voir [Organiser](./organizing).

:::

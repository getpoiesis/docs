# Réglages d’écriture

Dans **Réglages → Réglages d’écriture**, vous choisissez deux choses :

- Ce que φ vous dit de votre écriture : votre série, un rythme hebdomadaire,
  la lisibilité, etc. φ appelle ces indications des **signaux**.
- Les lieux que chaque mode (**Écrire**, **Notes**, **Journal**) affiche dans
  sa barre latérale.

Chaque coffre a ses propres réglages d’écriture. Un coffre est le dossier qui
contient vos textes (voir [Coffres](./vaults)). Un coffre consacré à un roman
et un coffre consacré à un journal peuvent donc n’afficher, chacun, que ce
qui leur est utile.

## Régler un coffre {#set-up-a-vault}

1. Ouvrez les **Réglages** : appuyez sur `⌘,`, ou cliquez sur les curseurs à
   côté du nom du coffre.
2. Choisissez **Réglages d’écriture**.
3. Sous **Signaux**, choisissez ce que φ vous dit de votre écriture.
4. Sous **Modes**, cliquez sur **Écrire**, **Notes** ou **Journal** pour
   choisir les lieux que ce mode propose.
5. Pour reprendre les mêmes réglages dans un autre coffre, cliquez sur
   **Enregistrer sous…**, sous **Réglages enregistrés**.

Vos modifications s’appliquent au coffre où vous vous trouvez. Un nouveau
coffre démarre avec les valeurs par défaut indiquées ci-dessous.

## Choisir ce que φ vous dit {#choose-what-φ-tells-you}

| Signal | Ce qu’il fait | Au départ |
| --- | --- | --- |
| **Démarrer les sessions automatiquement** | Lance le chronomètre d’une session d’écriture dès que vous tapez la première lettre. Si vous le désactivez, une session ne démarre que lorsque vous le demandez : `⌘P` → **Démarrer la session d’écriture** (et **Terminer la session d’écriture**). | Activé |
| **Statistiques de lisibilité** | Ajoute le niveau de lecture et la longueur des phrases aux **Statistiques du document**. Pour les ouvrir, cliquez sur le nombre de mots dans le coin de la page, puis cliquez dessus une seconde fois. | Désactivé |
| **Série** | La façon dont votre série d’écriture s’affiche sur l’Accueil et dans le calendrier : **Flamme et compte**, **Jours simples** ou **Désactivée**. | **Flamme et compte** |
| **La semaine commence le** | Le premier jour de la semaine. Le calendrier et votre rythme hebdomadaire s’en servent. Ce réglage vaut pour tous les coffres. | Lundi |
| **Rythme hebdomadaire** | Un nombre de jours d’écriture à atteindre par semaine : **Aucun**, ou de **1/semaine** à **7/semaine**. φ compte les sept derniers jours : un jour manqué ne remet donc pas le compteur à zéro. | **Aucun** |

Une journée compte dans votre série quand vous écrivez un nombre minimal de
mots. Vous fixez ce nombre dans **Réglages → Éditeur → Série d’écriture →
Minimum de mots / jour** (50 ou plus).

## Choisir les lieux de chaque mode {#choose-each-modes-places}

Sous **Modes**, chaque mode utilisé par le coffre a sa ligne. La ligne
indique **Suit le coffre** tant que vous n’y avez rien modifié. Ensuite, elle
indique **Diffère**.

Cliquez sur une ligne pour l’ouvrir. Vous y trouvez :

- **Les lieux** que propose la barre latérale de ce mode. Chacun a son
  interrupteur.
- **Les interrupteurs des signaux**, pour ce mode uniquement.
- **Listes de tâches** : la possibilité, ou non, de commencer une nouvelle
  liste de tâches dans ce mode. Un document qui contient déjà une liste de
  tâches la conserve, et vous pouvez toujours en cocher les cases.

Pour qu’un mode reprenne les réglages du coffre, cliquez sur **Suivre le
coffre à nouveau**.

Ce tableau indique les lieux que chaque mode propose au départ :

| Lieu | Écrire | Notes | Journal |
| --- | :---: | :---: | :---: |
| **Personnages** | ✓ | | |
| **Auteurs** | ✓ | | |
| **Recherche** | ✓ | jamais | |
| **Tableaux** | ✓ | ✓ | |
| **Graphe** | ✓ | ✓ | |
| **Calendrier** | ✓ | ✓ | ✓ |
| **Commencer les pages du matin du jour** | | | ✓ |

- **Écrire et Notes.** Vous pouvez activer n’importe lequel des autres lieux,
  sauf les pages du matin. Par exemple, vous pouvez activer **Personnages**
  dans Notes. **Recherche** est réservé à Écrire.
- **Journal.** Il ne propose que le calendrier et les pages du matin. C’est
  voulu, pour que Journal reste simple. Si vous désactivez **Commencer les
  pages du matin du jour**, **Pages du matin** et **Scellées** disparaissent
  de la barre latérale de Journal.
- **Listes de tâches.** Elles sont activées dans Notes et désactivées dans
  Écrire et dans Journal, car on s’en sert surtout dans les notes. Si vous
  tenez des listes de tâches dans un manuscrit, activez-les ici pour Écrire.

## Utiliser des réglages dans un autre coffre {#use-a-setup-in-another-vault}

**Réglages enregistrés** conserve des copies de vos réglages, chacune sous
un nom.

- **Enregistrer sous…** donne un nom aux réglages actuels et en garde une
  copie. Si vous modifiez ce coffre par la suite, la copie ne change pas.
- **Utiliser dans ce coffre** remplace les réglages de ce coffre par ceux
  que vous avez enregistrés.
- **Utiliser dans un autre coffre…** applique les réglages enregistrés à un
  autre coffre.
- **Renommer** et **Supprimer** modifient la liste. Si vous supprimez des
  réglages enregistrés, les coffres qui les utilisent ne changent pas.

:::note Masquer ne supprime jamais rien

Désactiver un élément ne fait que le masquer. Si vous désactivez les pages
du matin, vos pages sont toujours dans le coffre, intactes. Réactivez les
pages du matin, et vos pages réapparaissent.

:::

## Ce que les réglages d’écriture ne changent pas {#what-setup-doesnt-change}

- **Les modes d’un coffre.** Vous les choisissez dans **Réglages → Coffre →
  Espaces**. Voir [Coffres](./vaults).
- **Les outils de l’éditeur.** Les citations, la table des matières et les
  modèles n’ont pas d’interrupteur. Ils sont disponibles dans tous les types
  de documents qui peuvent s’en servir.
- **Votre travail.** Rien, sur cette page, ne déplace ni ne supprime un
  document.

# Pages manuscrites

Avec φ sur iPad ou sur une tablette Android (bientôt disponible), vous
pouvez écrire un document à la main avec un stylet, sur papier ligné,
pointillé, quadrillé ou blanc.

Quand vous ouvrez ce document sur votre ordinateur, vous voyez les pages
telles que vous les avez écrites, quelle que soit la tablette, nettes à
toutes les tailles.

On n’écrit à la main que sur une tablette. Sur l’ordinateur, vous pouvez
lire les pages, modifier leur texte et revenir à des versions antérieures.

## Lire les pages ou leur texte {#read-the-pages-or-their-text}

Un document manuscrit a deux vues. Choisissez-en une en haut de la page :

- **Encre** montre vos pages manuscrites sur leur papier, l’une sous
  l’autre. Le stylo et le crayon gardent l’épaisseur que vous leur avez
  donnée. Le surligneur reste sous les mots.
- **Texte** montre les mots lus dans votre écriture. Vous pouvez les
  modifier ici comme n’importe quel document, et vos changements arrivent
  aussi sur vos tablettes.

Un document manuscrit n’a qu’un texte. Tant que vous ne le modifiez pas, il
suit votre écriture : quand une tablette lit de nouveaux mots sur les pages,
le texte se met à jour. Une fois que vous l’avez modifié, φ ne le change
plus de lui-même. Sur la tablette, **Mettre à jour depuis l’écriture** le
remet en accord avec les pages.

Tant qu’un document est ouvert, φ se souvient de la vue choisie.

## Versions antérieures {#earlier-versions}

Les versions d’un document manuscrit gardent ses pages en plus de son texte.
Pour en voir une, ouvrez l’historique du document et choisissez une
version :

- **Encre** montre les pages telles qu’elles étaient alors.
- **Afficher les changements** montre les pages telles qu’elles sont
  maintenant. Les traits ajoutés depuis cette version sont en vert, ceux qui
  ont été retirés apparaissent en transparence.
- **Restaurer** rétablit les pages et le texte ensemble.

Les versions enregistrées avant φ 0.19 n’ont gardé que le texte. Elles
l’indiquent, et en restaurer une laisse les pages telles qu’elles sont.

## Couleurs {#colours}

L’encre noire et l’ardoise propre à φ changent avec votre
[thème de couleur](themes-and-languages). Par exemple, une page écrite en
noir s’affiche en blanc avec un thème sombre.

Les autres couleurs ne changent pas. Sur une page sombre, φ les éclaircit un
peu pour qu’elles restent lisibles.

## Une page illisible {#a-page-that-cant-be-read}

Si le fichier d’une page est abîmé, par exemple parce qu’il se
synchronisait encore quand vous avez ouvert le document, le message
*Impossible de lire cette page* s’affiche à sa place. Ouvrez le document
sur la tablette où il a été écrit. Une fois enregistré de nouveau, la page
s’affiche aussi sur l’ordinateur.

## Où sont rangées les pages {#where-the-pages-live}

φ garde les pages manuscrites dans votre [coffre](vaults), avec le document.
Un coffre est le dossier où φ range vos documents. Les pages se
synchronisent avec le document.

Les pages suivent aussi le document quand vous le mettez à la corbeille, le
restaurez ou le déplacez vers un autre coffre.

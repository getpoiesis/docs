# Pages manuscrites

Avec φ sur iPad (bientôt disponible), vous pouvez écrire un document à la
main avec l’Apple Pencil, sur du papier ligné, pointillé, quadrillé ou uni.

Quand vous ouvrez ce document sur votre ordinateur, vous retrouvez les pages
telles que vous les avez écrites. Elles restent nettes à n’importe quelle
taille.

L’écriture à la main n’est possible que sur l’iPad. Sur l’ordinateur, vous
pouvez lire les pages et modifier leur texte.

## Lire les pages ou leur texte {#read-the-pages-or-their-text}

Un document manuscrit a deux vues. Choisissez-en une en haut de la page :

- **Encre** montre vos pages manuscrites sur leur papier, l’une sous l’autre.
  Les traits de stylo et de crayon gardent l’épaisseur que vous leur avez
  donnée. Le surligneur passe sous les mots.
- **Texte** montre les mots que l’iPad a lus dans votre écriture. Il faut
  d’abord demander cette lecture à l’iPad. Vous pouvez ensuite modifier les
  mots ici, comme dans n’importe quel autre document, et vos changements
  repartent vers l’iPad.

Tant qu’un document reste ouvert, φ se souvient de la vue que vous avez
choisie pour lui.

## Couleurs {#colours}

L’encre noire et la couleur ardoise propre à φ s’adaptent à votre
[thème de couleur](themes-and-languages). Par exemple, une page écrite en
noir s’affiche en blanc avec un thème sombre.

Les autres couleurs ne changent pas. Sur une page sombre, φ les éclaircit
simplement un peu pour qu’elles restent lisibles.

## Une page qui ne s’affiche que sur l’iPad {#a-page-that-only-shows-on-the-ipad}

Une page enregistrée par une ancienne version de φ pour iPad ne peut pas
s’afficher sur l’ordinateur. À sa place, vous voyez le message *Pour
l’instant, cette page s’affiche sur l’iPad*.

Pour y remédier, ouvrez le document sur l’iPad avec la dernière version de φ.
La page s’affichera ensuite aussi sur l’ordinateur.

## Où sont rangées les pages {#where-the-pages-live}

φ range les pages manuscrites dans votre [coffre](vaults), avec le document.
Un coffre est le dossier où φ range vos documents. Les pages se synchronisent
en même temps que le document.

Elles le suivent aussi quand vous le déplacez vers la corbeille, quand vous le
restaurez ou quand vous le déplacez vers un autre coffre.

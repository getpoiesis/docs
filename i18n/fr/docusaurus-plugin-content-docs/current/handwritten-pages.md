# Pages manuscrites

φ sur iPad (bientôt disponible) vous permet d’écrire un document à la main,
avec l’Apple Pencil, sur papier ligné, pointillé, quadrillé ou blanc. Ouvrez
ce document sur votre ordinateur : ses pages sont là, telles que vous les avez
écrites, nettes à toutes les tailles. Les pages ne s’écrivent que sur l’iPad ;
sur l’ordinateur, vous les lisez.

## Lire les pages ou leur texte

Un document manuscrit a deux faces, à choisir en haut de la page :

- **Encre** : les pages, l’une sous l’autre, sur leur papier. Le stylo et le
  crayon gardent le poids de votre main, et le surligneur reste sous les mots.
- **Texte** : les mots tirés de votre écriture, une fois que vous les avez
  demandés à l’iPad. Vous pouvez les modifier ici comme n’importe quel
  document, et vos changements repartent vers l’iPad.

φ se souvient de la face choisie pour chaque document tant qu’il reste ouvert.

## Couleurs

L’encre noire et l’ardoise propre à φ suivent votre [thème de couleur](themes-and-languages) :
une page écrite en noir se lit en blanc avec un thème sombre. Les autres
couleurs restent les mêmes, un peu éclaircies sur une page sombre pour rester
lisibles.

## Une page qui ne s’affiche que sur l’iPad

Une page enregistrée par une version antérieure de φ pour iPad indique
*Pour l’instant, cette page s’affiche sur l’iPad*. Ouvrez le document sur
l’iPad avec la dernière version de φ, et elle s’affichera ici aussi.

## Où vivent les pages

Les pages sont gardées dans votre coffre avec le document, et se
synchronisent avec lui. Mettre le document à la corbeille, le restaurer ou le
déplacer vers un autre [coffre](vaults) emporte ses pages.

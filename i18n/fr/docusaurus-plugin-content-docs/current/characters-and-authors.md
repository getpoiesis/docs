# Personnages et auteurs

Les **personnages** sont les personnes de votre œuvre, chacune gardée sur sa
fiche, pour qu’un `@` les retrouve partout où vous écrivez. Les **auteurs**
sont les noms sous lesquels vous publiez. Un profil d’auteur signe vos
livres : la signature, «  À propos de l’auteur  », et les coordonnées sur un
manuscrit que vous envoyez.

Les deux vivent dans **Écrire**, sous **Monde** dans la barre latérale. `⌘K`
trouve un personnage par son nom depuis n’importe quel mode, et mène à l’une
ou l’autre liste.

## Ajouter un personnage {#add-a-character}

1. Dans **Écrire**, cliquez sur **Personnages** sous **Monde**.
2. Cliquez sur **+** (**Nouveau personnage**).
3. Remplissez sa fiche. Chaque champ s’enregistre quand vous le quittez.
4. Dans n’importe quel document, tapez `@` et le début de son nom pour le
   mentionner.

## La fiche d’un personnage {#a-characters-sheet}

| Champ | À quoi il sert |
| --- | --- |
| **Nom** | Son nom complet. |
| **Nom d’utilisateur** | L’`@identifiant`. |
| **Alias** | D’autres noms, séparés par des virgules. Chacun fonctionne avec `@`, et tous ramènent à la même personne. |
| **Appartient à** | **Tous les projets** (partagé), ou les projets où figure le personnage : un livre, ou plusieurs pour une série. |
| **Personne réelle** | Cochez-la pour quelqu’un de réel ; **Rôle et traits** devient **Détails**. |
| **Rôle et traits** | Quelques lignes sur qui il est. |
| **Notes** | Passé, apparence, évolution, n’importe quoi. |
| **Lié depuis** | Chaque document qui le mentionne, avec un nombre. Cliquez sur l’un d’eux pour l’ouvrir. |
| **Recherche** et **Notes** | Les pages de recherche et les notes à son sujet : **Nouvelle page de recherche**, **Lier une recherche…**, **Nouvelle note à ce sujet** et **Lier une note…** (voir [Recherche](./research)). |

**Supprimer**, au pied de la fiche, envoie le personnage à la corbeille. Le
champ de recherche de la liste porte sur les noms, les noms d’utilisateur et
les alias.

## Garder le monde de chaque livre à part {#keep-each-books-world-apart}

Un personnage appartient au projet dans lequel vous le créez. Ouvrez un projet
et choisissez **Personnages** en dessous, dans la barre latérale : ses propres
personnages viennent d’abord, puis les personnages partagés, marqués
**Partagé**. Créer un personnage là, ou avec `@` pendant que vous écrivez l’un
de ses chapitres, le place dans ce projet.

- **Une série :** sur la fiche d’un personnage, **Appartient à** permet de
  cocher plusieurs projets, et il figure dans chacun.
- **Tout le monde :** choisissez **Tous les projets** pour les personnes qui
  appartiennent à toute votre œuvre, comme des personnes réelles ou un
  narrateur récurrent.
- **Monde → Personnages** dans la barre latérale montre toujours tout le monde
  dans le coffre.
- Déplacer un projet vers un autre coffre emmène ses propres personnages ;
  ceux qu’il partage avec d’autres projets restent.

## Mentionner un personnage {#mention-a-character}

Tapez `@` dans un document et commencez un nom. φ propose les personnages du
projet dans lequel vous écrivez et les personnages partagés, une fois pour
leur nom complet et une fois pour chaque alias. Les accents ne le gênent
pas : «  jose  » trouve José. Choisissez-en un et la mention est insérée.

- Une mention par le nom complet suit le personnage si vous le renommez plus
  tard.
- Cliquez sur une mention pour ouvrir la fiche du personnage.
- Tapez un nom que personne ne porte encore, et la dernière suggestion est
  **Nouveau personnage**. Choisissez-la et φ crée le personnage et le
  mentionne d’un seul geste.

À l’export, une mention devient du texte simple : le nom ou l’alias que vous
avez choisi, sans le `@`. Les pages du matin n’ont pas de suggestions `@`,
pour garder leur page dépouillée.

## Créer un profil d’auteur {#make-an-author-profile}

<img src="/img/app/authors-light.png" alt="Un profil d’auteur : photo, nom, nom de plume, e-mail, site web, biographie, biographie courte, crédit photo, et l’adresse postale et le téléphone pour les envois" width="1600" height="1000" loading="lazy" decoding="async" />
<img src="/img/app/authors-dark.png" alt="Un profil d’auteur : photo, nom, nom de plume, e-mail, site web, biographie, biographie courte, crédit photo, et l’adresse postale et le téléphone pour les envois" width="1600" height="1000" loading="lazy" decoding="async" />

1. Dans **Écrire**, cliquez sur **Auteurs** sous **Monde**, puis sur **+**
   (**Nouvel auteur**).
2. Remplissez le profil. Chaque champ s’enregistre quand vous le quittez.
3. Associez le profil à un projet : sur la page du projet, choisissez-le sous
   **Réglages** → **Profil d’auteur**, ou ajoutez-le sous **Détails du
   livre** → **Personnes** (voir [Détails du livre](./book-details)).

## Ce que signe chaque partie du profil {#what-each-part-of-the-profile-signs}

| Champ | Où il apparaît |
| --- | --- |
| **Nom** | Votre nom légal. Il ouvre le bloc de coordonnées sur la première page d’un manuscrit, et donne le nom de famille de son titre courant. |
| **Nom de plume / signature** | Le nom sur le livre : la couverture, la page de titre, la signature. Laissez-le vide s’il est identique à votre nom. |
| **Photo** | Cliquez sur le carré à côté du nom pour en ajouter une. Elle accompagne «  À propos de l’auteur  ». **Retirer la photo** l’enlève. |
| **Crédit photo** | Imprimé sous la photo. |
| **Biographie** | «  À propos de l’auteur  » à la fin du livre, tiré du profil du premier auteur. |
| **Biographie courte** | Une ligne ou deux pour la quatrième de couverture. Sans elle, φ utilise le premier paragraphe de **Biographie**. |
| **E-mail** et **Site web** | Votre e-mail figure aussi dans le bloc de coordonnées d’un manuscrit. |
| **Adresse postale** et **Téléphone** | Sous **Pour les envois** : le reste du bloc de coordonnées sur la première page d’un manuscrit. |
| **Agent** | Si vous avez un agent, son nom, son agence, son adresse, son téléphone et son e-mail, un par ligne. Ils remplacent vos propres coordonnées sur la première page du manuscrit. |
| **Autres titres (page «  Du même auteur  »)** | Vos autres livres, chacun avec une année si vous le souhaitez. Ils forment la page «  Du même auteur  » à la fin d’un livre. |
| **Signé sur** | Les projets qui portent cette signature. Cliquez sur l’un d’eux pour l’ouvrir. |

Quand vous préparez un manuscrit pour un agent, l’export vous indique ce qui
manque à la première page et propose **Ouvrir le profil d’auteur** (voir
[Envoyer à un agent ou un éditeur](./send-to-an-agent)).

**Supprimer** envoie le profil à la corbeille.

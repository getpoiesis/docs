# Personnages et auteurs

Les **personnages** sont les personnes de votre œuvre. Chacun a sa fiche, et
vous pouvez le mentionner dans n’importe quel document en tapant `@`. Les
**auteurs** sont les noms sous lesquels vous publiez. C’est du profil d’auteur
qu’un livre tire sa signature et sa page « À propos de l’auteur ». C’est de
lui aussi que viennent les coordonnées qui figurent sur un manuscrit que vous
envoyez.

Les uns et les autres se trouvent dans **Écrire**, sous **Monde** dans la
barre latérale. Depuis n’importe quel mode, `⌘K` retrouve un personnage
d’après son nom et ouvre l’une ou l’autre liste.

## Ajouter un personnage {#add-a-character}

1. Dans **Écrire**, cliquez sur **Personnages** sous **Monde**.
2. Cliquez sur **+** (**Nouveau personnage**).
3. Remplissez la fiche du personnage. φ enregistre chaque champ dès que vous
   le quittez.
4. Pour mentionner le personnage, tapez `@` suivi du début de son nom dans
   n’importe quel document.

## La fiche d’un personnage {#a-characters-sheet}

| Champ | À quoi il sert |
| --- | --- |
| **Nom** | Son nom complet. |
| **Nom d’utilisateur** | Son `@identifiant`. |
| **Alias** | D’autres noms, séparés par des virgules. Chacun fonctionne avec `@`, et tous mènent au même personnage. |
| **Appartient à** | **Tous les projets** (personnage partagé), ou les projets où figure le personnage : un seul livre, ou plusieurs pour une série. |
| **Personne réelle** | Cochez la case s’il s’agit de quelqu’un qui existe. **Rôle et traits** devient alors **Détails**. |
| **Rôle et traits** | Quelques lignes pour dire qui il est. |
| **Notes** | Son passé, son apparence, son évolution au fil de l’histoire, ou quoi que ce soit d’autre. |
| **Lié depuis** | Tous les documents qui le mentionnent, avec le nombre de mentions. Cliquez sur l’un d’eux pour l’ouvrir. |
| **Recherches** et **Notes** | Les pages de recherche et les notes qui le concernent : **Nouvelle page de recherche**, **Lier une recherche…**, **Nouvelle note à ce sujet** et **Lier une note…** (voir [Recherche](./research)). |

**Supprimer**, en bas de la fiche, envoie le personnage à la corbeille.

Le champ de recherche au-dessus de la liste des personnages cherche dans les
noms, les noms d’utilisateur et les alias.

## Séparer le monde de chaque livre {#keep-each-books-world-apart}

Un personnage appartient au [projet](./collections) dans lequel vous le créez.
Pour voir les personnages d’un projet, ouvrez le projet et choisissez
**Personnages** en dessous de lui, dans la barre latérale. Les personnages
propres au projet viennent en premier. Les personnages partagés suivent, avec
la mention **Partagé**.

Un nouveau personnage entre dans ce projet quand vous le créez dans cette
liste, ou avec `@` pendant que vous écrivez l’un des chapitres du projet.

- **Une série :** sur la fiche du personnage, cochez plusieurs projets sous
  **Appartient à**. Le personnage figure alors dans chacun d’eux.
- **Toute votre œuvre :** choisissez **Tous les projets** pour quelqu’un qui
  apparaît partout, par exemple une personne réelle ou un narrateur que vous
  reprenez.
- **Tout le coffre :** **Monde → Personnages**, dans la barre latérale,
  continue d’afficher tous les personnages du [coffre](./vaults), le dossier
  qui contient vos textes.
- **Déplacer un projet :** quand vous déplacez un projet vers un autre coffre,
  ses propres personnages le suivent. Un personnage qu’il partage avec
  d’autres projets reste où il est.

## Mentionner un personnage {#mention-a-character}

1. Dans un document, tapez `@` et commencez à taper un nom. φ propose les
   personnages du projet dans lequel vous écrivez, ainsi que les personnages
   partagés.
2. Choisissez une suggestion. φ insère la mention dans le texte.

<img src="/img/app/mention-suggestions-light.png" alt="Un chapitre avec une arobase et une lettre tapées, et la liste des personnages correspondants ouverte" width="1600" height="1000" loading="lazy" decoding="async" />
<img src="/img/app/mention-suggestions-dark.png" alt="Un chapitre avec une arobase et une lettre tapées, et la liste des personnages correspondants ouverte" width="1600" height="1000" loading="lazy" decoding="async" />

Chaque personnage apparaît dans les suggestions une fois pour son nom complet
et une fois pour chacun de ses alias. Inutile de taper les accents : « jose »
trouve José.

- Si vous mentionnez un personnage par son nom complet et que vous le renommez
  plus tard, la mention change elle aussi.
- Cliquez sur une mention pour ouvrir la fiche du personnage.
- Si vous tapez un nom qu’aucun personnage ne porte, la dernière suggestion
  est **Nouveau personnage**. Choisissez-la : φ crée le personnage et ajoute
  la mention.

À l’export, une mention devient du texte ordinaire : le nom ou l’alias que
vous avez choisi, sans le `@`.

Les pages du matin n’ont pas de suggestions `@`.

## Créer un profil d’auteur {#make-an-author-profile}

<img src="/img/app/authors-light.png" alt="Un profil d’auteur : photo, nom, nom de plume, e-mail, site web, biographie, biographie courte, crédit photo, puis l’adresse postale et le téléphone pour les envois" width="1600" height="1000" loading="lazy" decoding="async" />
<img src="/img/app/authors-dark.png" alt="Un profil d’auteur : photo, nom, nom de plume, e-mail, site web, biographie, biographie courte, crédit photo, puis l’adresse postale et le téléphone pour les envois" width="1600" height="1000" loading="lazy" decoding="async" />

1. Dans **Écrire**, cliquez sur **Auteurs** sous **Monde**.
2. Cliquez sur **+** (**Nouvel auteur**).
3. Remplissez le profil. φ enregistre chaque champ dès que vous le quittez.
4. Ajoutez le profil à un projet. Sur la page du projet, choisissez-le sous
   **Réglages** → **Profil d’auteur**. Ou bien ajoutez-le sous **Détails du
   livre** → **Personnes** (voir [Détails du livre](./book-details)).

## Ce que signe chaque partie du profil {#what-each-part-of-the-profile-signs}

| Champ | Où il apparaît |
| --- | --- |
| **Nom** | Votre nom à l’état civil. C’est la première ligne du bloc de coordonnées, sur la première page d’un manuscrit. Son nom de famille est repris dans le titre courant du manuscrit. |
| **Nom de plume / signature** | Le nom qui figure sur le livre : la couverture, la page de titre, la signature. Laissez ce champ vide s’il est identique à votre nom. |
| **Photo** | Cliquez sur le carré à côté du nom pour en ajouter une. Elle accompagne « À propos de l’auteur ». **Retirer la photo** l’enlève. |
| **Crédit photo** | Imprimé sous la photo. |
| **Biographie** | La page « À propos de l’auteur » à la fin du livre, tirée du profil du premier auteur. |
| **Biographie courte** | Une ligne ou deux pour la quatrième de couverture. Si ce champ est vide, φ prend le premier paragraphe de **Biographie**. |
| **E-mail** et **Site web** | Votre e-mail figure aussi dans le bloc de coordonnées d’un manuscrit. |
| **Adresse postale** et **Téléphone** | Sous **Pour les envois** : le reste du bloc de coordonnées, sur la première page d’un manuscrit. |
| **Agent** | Si vous avez un agent : son nom, son agence, son adresse, son téléphone et son e-mail, un par ligne. Ces informations remplacent vos propres coordonnées sur la première page du manuscrit. |
| **Autres titres (page « Du même auteur »)** | Vos autres livres, chacun avec son année si vous le souhaitez. Ils composent la page « Du même auteur » à la fin d’un livre. |
| **Signé sur** | Les projets qui utilisent ce profil. Cliquez sur l’un d’eux pour l’ouvrir. |

Quand vous préparez un manuscrit pour un agent, l’export vous signale ce qui
manque sur la première page. Il propose alors **Ouvrir le profil d’auteur**
(voir [Envoyer à un agent ou un éditeur](./send-to-an-agent)).

**Supprimer** envoie le profil à la corbeille.

# Recherche

Une **page de recherche** rassemble la documentation qui nourrit votre
écriture : sources, faits, lieux, chronologies. Vous liez chaque page de
recherche à ce dont elle parle : un chapitre, un [projet](./collections.md) ou
un personnage. Vos recherches apparaissent alors à côté de ce chapitre, de ce
projet ou de ce personnage, sans se mêler au texte du livre.

## Commencer une page de recherche pour un chapitre {#start-a-research-page-for-a-chapter}

1. Ouvrez le chapitre.
2. Ouvrez le [panneau Infos](./finding-your-way.md#the-info-panel) (`⇧⌘I`) et
   choisissez **Liens**.
3. Sous **Recherche**, cliquez sur **Nouvelle page de recherche**. La
   nouvelle page est déjà liée au chapitre.
4. Donnez un titre à la page et écrivez. Une page de recherche s’écrit comme
   n’importe quel autre document, avec des titres, des listes, des citations
   et des liens.

Sous son titre, la page indique à quoi elle est liée (**Recherches pour**).
Cliquez sur l’un des noms pour l’ouvrir.

## Où se trouvent les recherches {#where-research-lives}

Les pages de recherche appartiennent au mode **Écrire**.

- **Les recherches du coffre.** Ouvrez **Monde** → **Recherche** dans la
  barre latérale (`⌘G` puis `R`). Quand aucune page de recherche n’est
  ouverte, la page les présente classées par mois. Chacune indique à quoi
  elle est liée. Un menu dans l’en-tête de la liste choisit les recherches
  affichées : **Ce projet**, **Hors projet**, **Tout**, ou un projet par son
  nom (voir
  [Personnages et auteurs](./characters-and-authors.md#choose-which-part-of-the-vault-a-list-shows)).
- **Les recherches d’un projet.** À l’intérieur d’un projet, cliquez sur
  l’onglet **Recherche** sous le nom du projet, dans la liste (`⌃4` ;
  **Alt+4** sur Windows et Linux). Cette liste contient les recherches liées
  au projet ou à l’un de ses chapitres.
- **Les recherches récentes.** L’**Accueil** d’Écrire affiche vos
  **Recherches récentes**, avec le sujet de chaque page. Quand tous les
  chapitres d’un projet sont marqués **Final**, les recherches de ce projet
  n’y figurent plus.

## Créer une page de recherche {#make-a-research-page}

Il y a trois façons de le faire :

- Cliquez sur **+** en haut d’une liste Recherche (**Nouvelle page de
  recherche**). Si vous le faites dans l’onglet Recherche d’un projet, ou
  dans une liste restreinte à un projet, la page appartient à ce projet.
- Appuyez sur `⌘K` et choisissez **Nouvelle page de recherche**.
- Cliquez sur **Nouvelle page de recherche** sous **Recherche**, dans
  l’onglet **Liens** d’un document, dans la page d’un projet ou dans la page
  d’un personnage. La page est liée au document, au projet ou au personnage
  que vous aviez sous les yeux.

## Lier la page à ce dont elle parle {#link-it-to-what-its-about}

1. Ouvrez les **Détails…** de la page de recherche (dans le menu **⋮** au-dessus de la page).
2. Sous **Recherches pour**, cliquez sur **Lier à…**.
3. Choisissez un **Document**, un **Projet** ou un **Personnage**.

Vous pouvez lier une page à autant d’éléments que vous voulez. Chaque lien
apparaît sous la forme d’une petite étiquette. Cliquez sur son **×** pour
retirer le lien.

## Voir les recherches liées à un élément {#see-the-research-for-something}

Trois endroits réunissent les recherches et les notes liées à ce sur quoi
vous travaillez :

- Le panneau Infos d’un document → **Liens**.
- La page d’un projet.
- La page d’un personnage.

Chacun comporte deux sections :

- **Recherche** contient les pages de recherche liées. Pour en ajouter une,
  utilisez **Nouvelle page de recherche** ou **Lier une recherche…**.
- **Notes** contient les notes ordinaires liées ici. Pour en ajouter une,
  utilisez **Nouvelle note à ce sujet** ou **Lier une note…**.

Le **×** à côté d’une entrée retire le lien.

Vous pouvez aussi lier une note ou une pièce à un chapitre, à un projet ou à
un personnage : utilisez **Lié à** dans sa page Détails. La note apparaît
alors à côté du chapitre, sans avoir besoin d’être une page de recherche.

:::note

Les pages de recherche n’apparaissent ni dans le [graphe](./links-and-graph.md)
ni dans les listes de Notes.

:::

# Maquettes et ajustements

Une **maquette** décide de l’allure de tout votre livre, à la manière dont les
éditeurs composent les leurs. Elle fixe :

- les polices ;
- la façon dont les chapitres s’ouvrent ;
- les titres courants (la ligne en haut de chaque page) et les numéros de
  page ;
- l’ornement placé entre les scènes.

Vous choisissez une seule maquette : le livre imprimé et le livre numérique
l’utilisent tous les deux. Pour changer quelques détails, passez par **Ajuster
la maquette** : vous gardez la maquette et ne modifiez que ces points-là.

## Choisir une maquette {#choose-a-design}

1. Ouvrez la page **Exporter** du projet (voir
   [Comment fonctionne l’export](./exporting.md)).
2. Choisissez **Livre imprimé** ou **Livre numérique**.
3. Choisissez la **Maquette**.
4. Appuyez sur **Aperçu** pour voir la maquette sur toutes les pages.

| Maquette | La page |
| --- | --- |
| **Classique** | La page habituelle des romans publiés. Police Garamond. Chaque chapitre s’ouvre sur une lettrine (une grande première lettre) et des petites capitales. Les titres courants donnent l’auteur et le titre. Un livre pour lequel aucune maquette n’a été choisie utilise Classique. |
| **Moderne** | Une page contemporaine. Police Source Serif. Un simple numéro au-dessus de chaque titre de chapitre. Des capitales espacées dans les titres courants. |
| **Littéraire** | Une page très aérée. Police Lora, avec un grand interligne. Les chapitres commencent bas dans la page. Le titre est en petites capitales. Un fleuron (un petit ornement en forme de feuille) sépare les scènes. |
| **Poésie** | Pour un recueil de poèmes. Chaque poème garde ses vers et ses retraits, avec de l’espace autour. |

Vos propres styles figurent aussi dans la liste, sous les maquettes. Voir
[Styles personnalisés](./custom-styles.md).

## Ajuster la maquette {#adjust-the-design}

1. Sur la page Exporter, repérez **Ajuster la maquette**, sous la maquette.
2. Cliquez dessus pour afficher les choix.
3. Modifiez ceux que vous voulez.

Au départ, chaque choix est réglé sur **Comme la maquette** : c’est la maquette
qui décide. Une fois refermée, la ligne indique combien de choix vous avez
modifiés.

| Choix | Ce qu’il change |
| --- | --- |
| **Police** | La police du texte : EB Garamond, Lora, Source Serif, Playfair Display, Inter ou Source Sans. |
| **Taille du texte** | De 9,5 à 13 pt (livre imprimé). |
| **Ouvertures de chapitre** | **Lettrine sur 2 lignes**, **Premiers mots en petites capitales** ou **Simple**. |
| **Entre les scènes** | L’ornement des sauts de scène : ⁂, \* \* \*, ❧, ou **Une ligne blanche**. |
| **Les chapitres commencent** | **En belle page** (sur une page de droite), comme dans la plupart des livres reliés, ou **À la page suivante**, sans page blanche (livre imprimé). |
| **Titres courants** | L’auteur et le titre en haut des pages, ou rien (livre imprimé). |
| **Sommaire** | Le nombre de niveaux que montre le sommaire, ou pas de sommaire du tout. |
| **Dédicace et épigraphe** | Si ces pages affichent leur titre et figurent au sommaire. Et aussi la place du texte sur la page : vers le haut, au premier tiers ou au centre. |

Les ajustements appartiennent au projet. Pour en annuler un, remettez-le sur
**Comme la maquette**.

## Tous les formats la suivent {#every-format-follows-it}

La maquette ne sert pas qu’au PDF d’impression. Le livre numérique, le fichier
Word et la page web l’utilisent aussi. Dans tous ces formats, les chapitres
s’ouvrent de la même façon :

- le numéro et le titre du chapitre ensemble ;
- la même lettrine ou les mêmes petites capitales ;
- le même ornement ;
- les mêmes polices.

Seule exception : le manuscrit destiné à un agent. Il reste sobre, parce qu’un
manuscrit doit l’être.

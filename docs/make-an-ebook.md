# Make an ebook

The **Ebook** tab makes an EPUB, the file every ebook store takes: Apple
Books, Kindle (KDP), Kobo and Google Play. It carries your cover, the book's
own pages and a contents list reading apps can use, set in the same design as
the printed book.

## Make the file

1. Open the project's **Export** page and choose **Ebook**.
2. Choose the **Design**. It's the same one the printed book uses, so the two
   match.
3. Read the check, and fix anything it lists.
4. Choose **Preview**, then **Ebook**, to page through it as a reading app
   would.
5. Press **Export EPUB** and choose where to save it.

## How an ebook differs from print

Readers choose their own type size, font and screen, so an ebook **reflows**:
there are no fixed pages, no page numbers and no running heads. What carries
over from the design is everything that isn't the page:

- the typefaces, which φ embeds in the file;
- how chapters open: the chapter number and title together, then a drop cap
  or the first words in small capitals;
- the ornament between scenes;
- the title page, copyright page, dedication, epigraph and "About the author".

## What the stores look for

The check covers what stores reject a book for:

- **A cover.** Stores list a book by it. It should be at least 1600 pixels on
  its long side; 2560 is best. Set it at the top of the project's page.
- **Descriptions for pictures** (alt text), for readers who can't see them.
- **An ISBN**, if you have one for the ebook: add it as **ISBN (ebook)** in
  [Book details](./book-details). KDP and Google Play don't need one.

The EPUB is checked against the EPUB standard as it's made.

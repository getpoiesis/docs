# Make an ebook

To sell or share your book as an ebook, you need an EPUB file. Every ebook
store takes it: Apple Books, Kindle (KDP), Kobo and Google Play. You make it
in the **Ebook** tab of the project's **Export** page.

The EPUB holds your cover, the book's own pages and a contents list that
reading apps can use. It uses the same design as the printed book.

## Make the file

1. Open the project's **Export** page.
2. Choose **Ebook**.
3. Choose the **Design**. The printed book uses the same design, so the two
   match.
4. Read the check. It lists anything you need to fix before you export. Fix
   each item.
5. Choose **Preview**, then **Ebook**. You see the book as a reading app
   shows it.
6. Press **Export EPUB**.
7. Choose where to save the file.

## How an ebook differs from print

In an ebook, the reader chooses the type size, the font and the screen. So the
text **reflows**: it fills whatever screen it is on. An ebook has no fixed
pages, no page numbers and no running heads.

These parts of the design are kept:

- the typefaces, which φ Poiesis puts inside the file;
- the way a chapter opens: the chapter number and title together, then a drop
  cap or the first words in small capitals;
- the ornament between scenes;
- the title page, copyright page, dedication, epigraph and "About the author".

## What the stores look for

Stores can reject a book when something is missing. The check looks for these
things:

- **A cover.** Stores show the cover when they list a book. It should be at
  least 1600 pixels on its long side; 2560 is best. Set the cover at the top
  of the project's page.
- **Descriptions for pictures** (alt text). These are for readers who can't
  see the pictures.
- **An ISBN**, if you have one for the ebook. Add it as **ISBN (ebook)** in
  [Book details](./book-details). KDP and Google Play don't need one.

Poiesis also checks the EPUB against the EPUB standard while it makes the file.

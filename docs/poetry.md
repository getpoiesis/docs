# Poetry & verse

Use a **Verse** block to write a poem. φ keeps your line breaks, your
stanzas and your indents exactly as you write them. Every export prints
them the same way.

## Write a poem

1. Open a poem in a [project](./collections). To start a new poem, click
   the **+** above the list and choose **New poem**.
2. Type `/verse` and press `Enter`, or press `⌥⌘V`. A verse block starts.
3. Write. Press `Enter` to start a new line.
4. Press `Enter` twice to leave a blank line between stanzas.
5. Press `⌘↩` to leave the verse and start a normal paragraph below it.

A project is a book or other long work made of several documents. You can
also write a poem on its own, as a draft in Write, or in a note or a journal
day: verse is offered in every document except morning pages. Epigraphs,
pull quotes and scene breaks are for documents in Write, in a project or
not.

## How verse is set

Verse has no box and no line beside it. It starts at the same margin as the
rest of the text, with no indent. Each line ends where you ended it.

- **Indents are kept.** If you start a line with spaces or `Tab`, the line
  keeps that indent on the page and in every export.
- **Lines are not justified or hyphenated.** φ does not stretch a line or
  split a word.
- **A line that is too long for the printed page** continues on the next
  line, indented. This is how publishers print verse.
- **A blank line** separates two stanzas.

Italic and other formatting work inside verse as they do in other text.

## Turn prose into verse, and back

If you already wrote the poem as paragraphs, you can change them to verse:

1. Select the paragraphs.
2. Choose **Verse**: type `/verse` or press `⌥⌘V`.

Each paragraph becomes a line. Each empty paragraph becomes a stanza break.

To change verse back to paragraphs, put the cursor inside the verse and
choose **Verse** again. Each line becomes its own paragraph.

## Open with an epigraph

An epigraph is a quotation at the start of a piece.

1. Type `/epigraph` and press `Enter`.
2. Write the quotation.
3. Press `↓` on the last line of the quotation. The cursor moves to the
   attribution field below.
4. Write the source there.

To put an epigraph at the start of the whole book, add it in the project's
[Book details](./book-details). φ then prints it on its own page.

## Set a line apart

- **Pull-quote** (`/pull-quote`): shows a line in large type. Use it for
  one statement that you want the reader to notice.
- **Scene break** (`/scene`): puts a centred ornament between sections. The
  ornament can be **Asterism** ⁂, **Stars** \* \* \*, **Fleuron** ❧ or
  **Blank space**. Point at the scene break to choose another one.

In an exported book, every scene break uses the ornament of the book's
design. To change that ornament, go to **Adjust the design → Between
scenes**.

| Block | Insert with |
| --- | --- |
| **Verse** | `/verse` or `⌥⌘V` |
| **Epigraph** | `/epigraph` |
| **Pull-quote** | `/pull-quote` |
| **Scene break** | `/scene` |

## Make a collection of poems

A project with the type **Poetry** is made of **Poems**, and the poems are
grouped into **Parts**. There are two ways to set the type:

- For a project you already have, open the project's page and go to
  **Settings → Type**.
- For a new project, choose **Poetry** when Write's Home offers **Start a
  project**.

A Poetry project works like any other project. You can put the poems in
order on **Contents**, add a dedication in the front matter, and set a
goal.

## Export with the Poetry design

1. Open the project's **Export** page.
2. Under **Print book** or **Ebook**, choose the **Poetry** design.

The Poetry design prints verse correctly. It keeps your lines, and it does
not justify or hyphenate them. It does not indent the first line. Each poem
starts on a new page, with space around it.

:::tip A size for poems
**Digest — 5.5 × 8.5 in** is a usual trim size for a printed collection of
poetry.
:::
